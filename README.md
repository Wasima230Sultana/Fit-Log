# FITLOG

A modern workout management app where users can explore exercises, view workout details, and organize their daily and saved workout plans.

## 🔗 Live Demo

[Visit FITLOG](YOUR_DEPLOY_LINK_HERE)

## 🛠️ Technologies Used

* Next.js
* TypeScript
* Tailwind CSS
* DaisyUI
* React Icons
* React Toastify

## ✨ Key Features

1. **Workout Library** – Browse and explore different exercises.
2. **Exercise Details** – View duration, calories, difficulty, sets, reps, rating, and instructions.
3. **Today's Plan** – Add exercises to your daily workout plan.
4. **Saved Workouts** – Save exercises for later.
5. **Sorting & Toasts** – Sort by duration, calories, or rating with instant notifications.
